# python-basics
# 实验一：Python基础入门

## 实验目标
掌握Python变量类型、函数定义、模块导入、列表/字典/元组等基础数据结构。

## 实验要求
1. 编写函数实现斐波那契数列生成（递归+迭代两种方式）
2. 使用列表推导式生成1-100的质数列表
3. 使用字典统计一段英文文本的词频
4. 编写一个简单的命令行计算器（加减乘除）
5. 使用argparse解析命令行参数
6. 编写完整的函数文档字符串(docstring)
